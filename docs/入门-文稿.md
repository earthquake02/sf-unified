> 载体说明：本文件是设置→入门（`GUIDE_GROUPS`）的**作者向文案底稿**。改这里 → 再手工同步到 `app/index.html` 的 `GUIDE_GROUPS`。  
> 状态：定稿（2026-10-30）｜对齐范围 B｜术语＝用户可见「小节」（CONTEXT 已同步）  
> 壳：保留四组左卡右详；不整本搬入功能书；stderr 不单独成卡。  
> Avoid：独立「作品结构」顶栏；远程 MCP／多 Server；大改 SETTINGS_TABS。

## 术语（统稿用，与 CONTEXT 一致）

| 用户可见 | 含义 | 入门写法注意 |
|---|---|---|
| 卷 / 章 / **小节** | 三级目录；小节＝正文最小单位（视角／标签／节拍／正文都挂这里） | 不把「场景」当设置／顶栏产品名；内部 id 仍可能叫 scene，入门不提；幕／部分不用 |
| 节拍 | 小节内剧情点清单 | 不是大纲行 |
| 状态边车 | 与小节正文同名的 `.json` | 入门不必展开；别叫 meta 文件 |
| 摘要／大纲 | 小节一句话概览 | 书的叫梗概，不叫简介 |
| 资源栏 | 主区左侧常驻：设定集／片段库／对话 | 有当前书才可用；不是第四个顶栏页 |
| 关系图谱 | 设定条目关系网 | 入口在设定集面板顶 |
| 剧情图谱 | 章／小节叶与因果边 | 入口在关系图谱右侧；与关系图谱分开 |
| 本机 MCP | 设置→AI 服务→MCP，stdio 单 Server | 优先「接文件系统」；stderr 只在 tip 提 |

## 组 start · 从这里开始

### ai-service · 接上 AI
- **GUIDE id:** `ai-service`
- **brief:** 先连上模型，后面写大纲、推演、补设定才用得上助手。
- **fig:** 设置 → AI 服务：服务商、模型与接口密钥
- **img:** `guide-ai-service.webp`（沿用）
- **from:** 04 · 提示词与 AI 服务
- **steps:**
  1. 打开「设置 → AI 服务」。
  2. 选服务商与模型，填入接口密钥（密钥只存本机，只发给你配置的服务商）。
  3. 点「测试连接」；通了再回写作页试一次助手。
  4. 若暂时不连网，仍可改目录与设定，只是 AI 相关按钮会不可用。
- **tip:** 密钥只存在本机数据夹。需要外接本机文件夹给助手时，见「本机 MCP」。换电脑导入数据后需重填密钥（导出包不含密钥）。
- **related:** `mcp`, `prompts`, `ai-panel`, `data-mgmt`

### mcp · 本机 MCP
- **GUIDE id:** `mcp`（新）
- **brief:** 让助手调用本机工具。新手优先「接文件系统」选一个目录，不必手改命令参数。
- **fig:** 设置 → AI 服务 → MCP：接文件系统
- **img:** TODO（截「接文件系统」小节＋已连接工具列表）
- **from:** 设置 · AI 服务 · MCP
- **steps:**
  1. 先完成「接上 AI」；MCP 本身需安装 Node.js（终端能运行 `npx`）。
  2. 打开「设置 → AI 服务 → MCP」。
  3. 在「接文件系统」里选文件夹或粘贴绝对路径，点「接文件系统并连接」；程序会自动写入 npx 命令、启用并连接。
  4. 连接成功后下方会出现工具列表；显示名／命令／参数仍可在高级区手改。
  5. 不用时断开或取消「启用 MCP」，助手回合就不带外部工具。
- **tip:** 若连接失败或超时，提示里可能会带上 Server 的 stderr 尾——先看目录是否存在、Node／npx 是否可用，再重试。改书稿与设定仍走助理提案卡，不会因为 MCP 而直接落盘。
- **related:** `ai-service`, `ai-panel`, `data-mgmt`

### my-novels · 我的小说
- **GUIDE id:** `my-novels`
- **brief:** 顶栏「我的小说」管理作品：新建、进入、编辑、导出；写之前先选对当前书。
- **fig:** 顶栏 · 我的小说：作品卡片列表
- **img:** `guide-my-novels.webp`（沿用）
- **from:** 01 · 作品与结构
- **steps:**
  1. 点顶栏「我的小说」。
  2. 新建一本，或点作品卡「进入」切过去（当前书名会跟着变）。
  3. 需要时「编辑」改书名／封面／目标字数；导出成稿走卡片「导出成稿」，备份走「设置 → 数据管理」。
- **tip:** 每本书的设定、章节、技能与文风蒸馏结果都挂在当前作品下，切书等于换一整套上下文。
- **related:** `structure`, `data-mgmt`, `storyboard`

## 组 pages · 顶部面板

### storyboard · 故事板
- **GUIDE id:** `storyboard`
- **brief:** 按卷／章看小节卡、节拍完成数与字数；点小节卡去写作页落字。建卷建章也在这里。
- **fig:** 故事板：卷 / 章 / 小节卡片与进度
- **img:** `guide-storyboard.webp`（沿用）
- **from:** 02 · 写作与故事板
- **steps:**
  1. 顶栏进「故事板」。
  2. 展开卷，点某个小节卡进入写作（点卷名／章名是重命名）。
  3. 卡面看字数、节拍完成数与摘要，判断这一章写到哪了。
  4. 新建结构：顶部「＋ 新卷」、卷行「＋章」、章行「＋小节」；调顺序／拆分用行内「⋯」（见「卷 · 章 · 小节」）。
- **tip:** 故事板管「这一章讲什么」；真正打字在「写作」。没有单独的「作品结构」顶栏；目录操作就在故事板与写作左栏。
- **related:** `writing`, `beats`, `structure`

### writing · 写作
- **GUIDE id:** `writing`
- **brief:** 正文编辑器：左栏卷 / 章结构树，右侧信息栏与 AI；可 @ 引用设定、目录等。
- **fig:** 写作页：编辑器 + 左栏结构树 + 右侧信息栏 / AI
- **img:** `guide-writing.webp`（沿用）
- **from:** 02 · 写作与故事板
- **steps:**
  1. 顶栏进「写作」，左栏高亮的就是当前章。
  2. 在正文区打字；三级目录下本章的多个小节会按顺序连续展示。
  3. 右侧信息栏看视角、标签、摘要、节拍与出场设定；资源栏取设定、片段与对话。
  4. 保存后回故事板看进度。
- **tip:** 助手吃的是你勾选的上下文。技能与文风蒸馏出的 Skill 在发送前的确认态勾选。左栏只列卷 / 章，资源栏是主区左侧常驻的设定集／片段库／对话。
- **related:** `left-sidebar`, `resource-rail`, `ai-panel`, `at-refs`, `skills`, `style-learn`

### review · 审阅
- **GUIDE id:** `review`
- **brief:** 项目体检、AI 审稿与修稿；把问题记回写作页或伏笔库，避免边写边改乱。
- **fig:** 审阅页：项目体检、AI 审稿与热力图
- **img:** `guide-review.webp`（沿用）
- **from:** 08 · 审阅与伏笔
- **steps:**
  1. 顶栏进「审阅」。
  2. 项目体检、统计、伏笔与设定出场热力图自动列出；点问题条目可跳到对应小节或设定。
  3. 要 AI 审稿时，在「AI 审稿」里选一章跑逐项目标核对；确认后才生成修订候选，采纳才写入。
  4. 把要改的点记回写作页或伏笔库。
- **tip:** 审阅不替代写作；大改仍回写作页。伏笔条目见「伏笔」。
- **related:** `foreshadow`, `writing`, `storyboard`

### settings-page · 设置
- **GUIDE id:** `settings-page`
- **brief:** 入门、系统、AI 服务、外观、提示词、技能、文风蒸馏、数据管理、更新都在这里。
- **fig:** 设置：左侧分组
- **img:** `guide-settings-page.webp`（沿用）
- **from:** 06 · 外观与设置
- **steps:**
  1. 顶栏进「设置」。
  2. 左侧切换：入门／系统／AI 服务／外观／提示词／技能／文风蒸馏／数据管理／更新。
  3. 改完一般立即生效；AI 密钥改完建议再测一次连接。
- **tip:** 「入门」就是功能卡导览；「更新」看版本说明。AI 服务页也包含本机 MCP。
- **related:** `onboarding-thin`, `ai-service`, `mcp`, `appearance`, `prompts`, `skills`, `style-learn`, `data-mgmt`

## 组 write-tools · 写作时常用

### left-sidebar · 写作页左栏
- **GUIDE id:** `left-sidebar`
- **brief:** 写作页左栏：卷 / 章结构树；点章进入本章正文，行内「⋯」做插入、移动、拆分。
- **fig:** 写作页左栏：卷 / 章结构树与 ⋯ 菜单
- **img:** `guide-left-sidebar.webp`（沿用；旧图若含小节行需重截）
- **from:** 02 · 写作与故事板
- **steps:**
  1. 在写作页看左栏：只列卷与章，不列小节行。
  2. 点章名进入本章连续正文；当前章会高亮。
  3. 卷 / 章行「⋯」可插入、移动、拆分、复制、删除；新建卷 / 章 / 小节回故事板更直接（见「卷 · 章 · 小节」）。
  4. 左栏可收起／展开；窄屏用覆盖槽临时打开。
- **tip:** 左栏是结构导航，不是正文工作台；视角、摘要、节拍与出场设定在右侧信息栏。
- **related:** `writing`, `structure`, `storyboard`, `resource-rail`

### structure · 卷 · 章 · 小节
- **GUIDE id:** `structure`（保留 id；标题由「作品结构」改为本标题）
- **brief:** 卷含章、章含小节（三级时）。新建与调整主要在故事板：顶部「＋ 新卷」、卷行「＋章」、章行「＋小节」，「⋯」调顺序／拆分。
- **fig:** 故事板 · 卷 / 章 / 小节行与 ＋ / ⋯
- **img:** TODO（旧 `guide-structure.webp` 若仍像「独立页」则废，重截故事板行与菜单）
- **from:** 01 · 作品与结构
- **steps:**
  1. 打开「故事板」。
  2. 顶部「＋ 新卷」建卷；卷行「＋章」建章；三级目录下章行「＋小节」建小节。
  3. 行「⋯」菜单：重命名、插入前／后、上移／下移、移到首末、拆分、复制、删除。
  4. 在「设置 → 系统」查看目录深度（二级／三级）；改为二级会合并同章小节且不可逆，先备份再改。
  5. 写作页左栏的卷 / 章「⋯」也能插入或调序；回到故事板或写作页，确认当前章／小节挂在正确节点。
- **tip:** 不要找「作品结构」顶栏——现行顶栏只有我的小说／故事板／写作／审阅／设置。目录怎么建，就在故事板与写作左栏。
- **related:** `my-novels`, `storyboard`, `writing`, `left-sidebar`

### beats · 节拍
- **GUIDE id:** `beats`
- **brief:** 小节（或章）里要发生的剧情点；故事板卡面看完成数，写作页右侧信息栏逐条改。
- **fig:** 写作页右侧：小节节拍列表
- **img:** `guide-beats.webp`（沿用）
- **from:** 02 · 写作与故事板
- **steps:**
  1. 打开写作页，在右侧信息栏找到「小节节拍」。
  2. 按情节添加／改写各节拍，一句到一小段。
  3. 写作时对照节拍推进；写完可勾完成。
  4. 点「生成」用 AI 出节拍候选，采用才写入；「成文」按节拍生成正文。
- **tip:** 节拍是提纲不是正文。大改情节先改节拍再改字，比直接在正文里挖补省事。
- **related:** `storyboard`, `writing`, `ai-panel`

### ai-panel · AI 助手
- **GUIDE id:** `ai-panel`
- **brief:** 写作页右侧：选模式与功能、勾选技能与推演强度、关联小节，再生成。
- **fig:** 写作页右侧：AI 面板（指令 / 对话）
- **img:** `guide-ai-panel.webp`（沿用）
- **from:** 05 · 助理与 @引用
- **steps:**
  1. 写作页打开右侧 AI。
  2. 选模式（指令＝单次请求；对话＝多轮）与功能（续写、润色、访谈／推演等）。
  3. 需要时勾选技能、调推演强度、关联小节、选上下文；确认后再生成。
  4. 发送先建会话，结果经「采用」才写入作品；不满意可改上下文或换功能再跑。
- **tip:** 重新打开面板会回到确认态，避免误触直接生成。若已接本机 MCP，对话模式的助手回合里才可能出现外部工具（见「本机 MCP」）。
- **related:** `writing`, `at-refs`, `skills`, `style-learn`, `prompts`, `mcp`

### skills · 技能
- **GUIDE id:** `skills`
- **brief:** 可复用的 AI 能力包（含文风蒸馏生成的 Skill）。在设置里管理，写作时在助手中勾选。
- **fig:** 设置 → 技能
- **img:** （可无，沿用）
- **from:** 技能 · 设置
- **steps:**
  1. 打开「设置 → 技能」，查看当前作品下已有技能。
  2. 启用／停用；需要时打开 Skill 文稿查看说明。
  3. 回写作页打开 AI，在发送前的确认态勾选本次要用的项。
  4. 文风蒸馏完成后，新 Skill 会出现在同一列表。
- **tip:** 技能按作品隔离。没用的先停用，减少助手上下文噪音。
- **related:** `ai-panel`, `style-learn`, `writing`, `settings-page`

### at-refs · @ 引用
- **GUIDE id:** `at-refs`
- **brief:** 在助手输入里 @ 内容、片段、提示词、设定或目录，把精确上下文塞进这一次生成。
- **fig:** 输入 @ 后的引用列表
- **img:** `guide-at-refs.webp`（沿用）
- **from:** 05 · 助理与 @引用
- **steps:**
  1. 在 AI 输入框键入 `@`（或点「@ 引用」）。
  2. 从列表选内容（正文／摘要／片段）、片段、提示词、设定或目录；目录可细到小节标题。
  3. 可多选；生成前看一眼上下文摘要。
- **tip:** @ 比整段粘贴更稳。设定要先在设定集里建好；被「从不包含」的设定不会出现在列表。技能不占 @ 列表，走确认态的「技能」勾选。
- **related:** `ai-panel`, `settings-set`, `writing`, `skills`

- **tip:** 图标色只影响辨认，不进正文。批量整理可用「提取设定」。关系网见「关系与剧情图谱」。

- **from:** 03 · 设定
- **steps:**
  1. 打开资源栏「设定集」，点顶部「关系图谱」或「剧情图谱」。
  2. 关系图谱：节点＝设定；拖移、搜索、多选（Shift）按工具栏说明操作；点节点可编条目。
  3. 剧情图谱：节点＝当前卷目录叶（有小节只铺小节，无小节铺章）；边请手拉「导致／相关」；双击或「打开写作」跳正文。
  4. 图谱内不改正文；剧情图谱 MVP 不做搜索／多选。
- **tip:** 两张图入口相邻、数据与用途都不同，别当成同一页的两个子页签。
- **related:** `resource-rail`, `settings-set`, `structure`, `writing`

### dialogue · 对话
- **GUIDE id:** `dialogue`（新）
- **brief:** 资源栏「对话」：按功能筛选与搜索历史会话；写作页点开会加载进副驾，其它页先只读预览。
- **fig:** 资源栏 · 对话
- **img:** TODO
- **from:** 05 · 助理与 @引用
- **steps:**
  1. 打开资源栏「对话」。
  2. 用功能标签筛选，或搜索标题／请求／结果。
  3. 点一条会话：在写作页会打开副驾并加载；在其它页先预览，进写作后再加载。
  4. 可归档、移回历史记录或删除；需要新开时用「＋ 新助理对话」。
- **tip:** 固定功能结果仍须「采用」才写入作品；对话列表只是入口与历史。
- **related:** `resource-rail`, `ai-panel`, `writing`

### extract · 提取设定
- **GUIDE id:** `extract`
- **brief:** 从正文或材料里捞人物／地点等候选，确认后再合并进设定集。
- **fig:** 提取设定：候选列表与确认写入
- **img:** `guide-extract.webp`（沿用）
- **from:** 03 · 设定
- **steps:**
  1. 在「我的小说」作品卡点「提取」；参考资料条目行也有「提取」；导入文档完成后可跟进提取。
  2. 选类型与范围，确认后才外发。
  3. 在候选里预览、勾选，再合并；无有效引文的候选会被丢弃。
  4. 回设定集改名称与归类。
- **tip:** 提取是草稿，务必人工过一眼；已有设定时走候选确认，避免静默覆盖手写字段。
- **related:** `settings-set`, `resource-rail`, `writing`, `ai-panel`

### snippets · 片段库
- **GUIDE id:** `snippets`
- **brief:** 写作页的素材碎片：选中文字或整小节存为片段，之后从资源栏「片段库」插入正文。
- **fig:** 资源栏 · 片段库列表与插入正文
- **img:** `guide-snippets.webp`（沿用；旧图若仍画「多片段」需重截）
- **from:** 02 · 写作与故事板
- **steps:**
  1. 写作页选中文字，点工具栏「存片段」（无选区时存整小节）。
  2. 打开资源栏「片段库」，按待处理／已完成查看。
  3. 点「插入正文」把片段放回当前小节的光标处或选中区；也可复制全文、编辑、标记完成或删除。
  4. 在正文输入 `/` 选「插入片段」，也能从片段库挑一条插入。
- **tip:** 片段库是全书素材，不属于某一章。提示词里可用 `{snippet.get("标题")}` 引入。灵感速记也放这里。
- **related:** `writing`, `resource-rail`, `at-refs`

### foreshadow · 伏笔
- **GUIDE id:** `foreshadow`
- **brief:** 登记已埋与待回收的伏笔（计划→已埋→已呼应→已回收）；审阅时看逾期／临近提醒。
- **fig:** 审阅 · 伏笔面板：状态与关联小节
- **img:** `guide-foreshadow.webp`（沿用）
- **from:** 08 · 审阅与伏笔
- **steps:**
  1. 在「审阅」页「伏笔」面板点「＋ 新建伏笔」；写作页右侧信息栏也能快捷新建。
  2. 填写标题、埋设位置、预期回收与状态。
  3. 写作推进时用右栏快捷标记「埋设／呼应／回收」，或回面板编辑。
  4. 审阅前看「⚠ 逾期／⏱ 临近」标记；有意安排的可点「豁免」。
- **tip:** 伏笔库是备忘，不会自动改正文。剧情图谱不替代伏笔四态。
- **related:** `review`, `writing`, `storyboard`, `settings-set`

## 组 prefs · 外观与其它

### appearance · 外观
- **GUIDE id:** `appearance`
- **brief:** 主题、配色、字体与编辑区观感；改完即时作用于写作页（全局，所有作品共用）。
- **fig:** 设置 → 外观
- **img:** `guide-appearance.webp`（沿用）
- **from:** 06 · 外观与设置
- **steps:**
  1. 打开「设置 → 外观」。
  2. 调主题、配色、字体或字号，看写作页是否舒适。
  3. 不满意再微调，一般无需重启。
- **tip:** 外观不管内容；换电脑需重新调或靠数据备份恢复偏好。
- **related:** `settings-page`, `writing`

### prompts · 提示词
- **GUIDE id:** `prompts`
- **brief:** 内置与自定义提示词模板；助手各功能可挂不同模板。
- **fig:** 设置 → 提示词
- **img:** `guide-prompts.webp`（沿用）
- **from:** 04 · 提示词与 AI 服务
- **steps:**
  1. 打开「设置 → 提示词」。
  2. 查看内置模板；需要时复制为自定义再改。
  3. 保存后，在 AI 功能里选用对应模板。
- **tip:** 提示词与技能分工：模板管「怎么问」，技能管「带什么能力／文风」。
- **related:** `ai-service`, `ai-panel`, `skills`

### style-learn · 文风蒸馏
- **GUIDE id:** `style-learn`
- **brief:** 从你的样章蒸馏文风，生成可勾选的 Skill；写作时让助手更贴你的笔法。
- **fig:** 设置 → 文风蒸馏：样章 → Skill
- **img:** `guide-style-learn.webp`（沿用）
- **from:** 文风蒸馏 · 设置
- **steps:**
  1. 打开「设置 → 文风蒸馏」。
  2. 选样章或粘贴能代表文风的段落（也可一键拼本书正文，规则以界面为准）。
  3. 确认发送后生成候选；可编辑再写入。
  4. 完成后在「技能」里会出现对应 Skill；写作时在 AI 面板勾选再生成。
- **tip:** 样章越像你平时要写的文体，效果越好。蒸馏结果按作品存放，可随时停用。
- **related:** `skills`, `ai-panel`, `writing`, `settings-page`
