## 一、产品形态与启动

### 1.1 运行形态

- Windows 单 exe：本地服务与程序窗口同一进程，浏览器页面由本地服务提供。
- 自带 API Key（BYOK）。
- 数据不存云端账号，而是存在用户指定的**数据文件夹**。
- 直接以文件方式打开页面，或从其他地址访问，只显示引导页，不进入应用。
- 首次使用：双击 `故事工坊.exe` → 浏览器打开 `127.0.0.1:端口` → 在服务控制台页填一次数据文件夹 → 以后双击即用。

### 1.2 数据与密钥

- 每本书一个文件夹；提示词、技能、文风、用量、大纲预设、设置等全局资产统一放在数据文件夹中。
- API Key 使用当前 Windows 账号加密保存在本机；设置文件和所有导出包都不含 Key 明文。
- 换电脑或换 Windows 账号后，旧 Key 解不开，需要在设置里重新填写；旧密文会移入数据夹回收站，不会静默销毁。
- 导出全部数据、导出本书 JSON、导出设定包、提示词整包，都不含 API Key。

### 1.3 只读与异常状态

出现以下情况时，应用进入只读或暂停写入，并在顶部显示常驻横幅：

- 数据由更新版本程序创建，当前程序只支持到旧数据结构版本。
- 数据文件被其他窗口或程序改动，发生写入冲突。
- 本地服务失联或重启。
- 本地服务版本过旧，无法加密保存 API Key。
- 最近一次写盘失败。

只读时仍可浏览、预览，但设置、建书、编辑、导入等写入入口会被禁用。冲突时可选择“重新载入”或“以本窗口为准覆盖”；覆盖会把对方版本先移入数据夹回收站。

### 1.4 自动保存

- 停笔约 1 秒即自动保存；连续打字时按“最长自动保存间隔”保存，可设 30–3600 秒。
- 设置 → 数据管理提供“立即写入”“从磁盘重新载入”“打开数据文件夹”“刷新状态”。
- 切换数据文件夹只改“认领哪个文件夹”，**不会自动搬家**；保存切换后整页重载并扫描新文件夹。

## 二、全局信息架构

### 2.1 顶部五页

| 顶栏 | 作用 | 无当前书时 |
|---|---|---|
| 我的小说 | 作品列表、新建、导入、切书 | 可用 |
| 故事板 | 卷章结构、时间轴/矩阵/卡片/清单、标签与批量 | 禁用 |
| 写作 | 正文编辑器、右栏信息、AI 副驾 | 禁用 |
| 审阅 | 项目体检、AI 审稿、伏笔、设定矛盾、热力图 | 禁用 |
| 设置 | 入门、系统、AI、外观、提示词、技能、文风、数据、更新 | 可用 |

### 2.2 常驻资源栏

有当前书时，主区左侧有一个常驻资源栏，三个入口互斥：

- **设定集**
- **片段库**
- **对话**

资源栏可收窄/展开、拖宽，选中项与宽度会记住。无当前书时强制窄栏且入口禁用。关系图谱、剧情图谱的入口在“设定集”面板顶部。

### 2.3 设置九页

`入门 / 系统 / AI 服务 / 外观 / 提示词 / 技能 / 文风蒸馏 / 数据管理 / 更新`

### 2.4 二级入口与旧视图

- 故事板内部有四个视图：**时间轴 / 矩阵 / 卡片 / 清单**，不是四个独立顶栏页面。
- 关系图谱、剧情图谱从“设定集”资源面板进入。
- 提示词库、文风蒸馏在设置内。
- **“大纲结构”不是当前五顶栏的独立页面**。日常结构操作走故事板节点菜单与写作页左栏节点菜单。写新入门时不要再把“作品结构”当成一个顶栏页面。

## 三、逐模块功能

### 3.1 我的小说

#### 作品卡

每张卡显示：封面、书名、作者、题材、总字数、卷/章/场景数、故事梗概。操作：进入、编辑、提取、导出成稿、删除。

#### 新建小说

字段：书名（必填）、作者、题材、AI 写作语言（默认中文）、故事梗概、目标字数、封面（JPG/PNG/WebP，大图自动压缩）、可选大纲结构模板。

空白建书会自动生成最小骨架：**第一卷、第一章、一个无题可写场景**。应用模板建书时，模板直接构成起始卷章，每章自带一个默认场景。

#### 编辑小说

同一套字段，封面可更换或移除。

#### 导入文档

入口在“我的小说”顶部，支持 `.docx / .txt / .md`：

- 纯本地解析，先展示提取文本与章节切分结果，核对确认后才写入。
- 可导入为**新书**（按章节切成卷/章/场景正文）。
- 也可存为某本书的**参考资料**（进入设定集“参考资料”分类，仅供查阅，不冒充正文或设定）。
- 支持章节标题识别、章号序列检查、编码探测；旧版 `.doc` 需先另存为 `.docx` 或 TXT。
- 取消或关窗零写入。

#### 删除小说

删除该书全部卷章场景、设定与对话记录，**不可恢复，不进入作品回收站**。

### 3.2 故事板

#### 顶部工具

- ＋新卷
- 时间轴 / 矩阵 / 卡片 / 清单四视图切换
- 范围：全书 / 当前章
- 标签管理
- 批量标签
- 卷/章/场景计数

#### 时间轴视图

- 按卷、章分栏展示场景卡。
- 场景卡显示：标题、字数、视角、标签、节拍完成数、摘要、手工布置与正文提及的设定标记。
- 拖拽场景可调整顺序；可拖到空章；二级目录下不能把场景调到别的章。
- 点击场景进入写作。
- 点击卷名/章名可重命名；行内“＋章”“＋小节”和“⋯”菜单。
- 角色/设定标记：● 手工布置，◆ 正文提及；两者可并存。

#### 矩阵视图

一次选一个维度：

- 摘要/大纲
- 视角
- 六个固定设定类型：角色 / 地点 / 物品 / 世界设定 / 支线 / 其他
- 标签

矩阵行为：

- 摘要格可就地编辑。
- 视角格显示值或缺省“—”。
- 设定类型格：勾选＝手工布置本景该条；◆＝正文提及，只读；两者不互相覆盖。
- 标签格：勾选即改本景该标签分配。
- 点行进入写作；摘要格例外，点内容先就地编辑。

#### 卡片视图

按卷章分组的纵排窄条：标题、摘要/正文前段节选、打开写作。整卡点击可就地编辑摘要；结构只读。

#### 清单视图

快速查阅表，点行进入写作。

#### 结构操作

卷、章、场景的“⋯”菜单支持：

- 重命名
- 编辑卷/章概要
- 禁用/恢复编号（展示与导出去编号，题名保留）
- 在此前/后插入
- 上移/下移、移到本卷首/末、全书首/末
- 从此拆分新章 / 新卷
- 复制本章正文/概要、复制场景
- 删除（进作品回收站）
- 场景：标签、历史版本
- 二级目录下禁用场景级插入/移动/拆分/复制/删除

场景之间还有“＋”热点：在此插入小节、拆分新章、拆分新卷。

#### 标签

- 标签定义是**本书级**：名称、颜色、顺序。
- 支持常用预设快捷创建。
- 改名、改色、调序会自动同步所有已打标场景。
- 删除定义会解除全书分配。
- 逐景分配、矩阵勾选、批量增减共用同一套定义。
- 批量标签：先勾选若干场景，再批量添加/移除；逐景逐文件写入，遇冲突或失败即停止后续，保留已成功项并出报告；可重试未完成项。

#### 范围与当前选中

四视图共用当前选中场景；切视图/切范围不清选择。卡片点击只设选中，“打开写作”才进入该景。

### 3.3 写作

#### 布局

写作页由四块组成：

1. 全局资源栏（设定集 / 片段库 / 对话）
2. 写作页左栏“结构栏”：只列卷、章，不列场景行
3. 中间正文区
4. 右侧“信息栏”，AI 面板打开时与信息栏共用同一右槽

左栏、右栏可独立收起/展开；右栏可拖宽；窄屏用单槽临时覆盖。滚动位置按书/景记忆。

#### 正文区

- 三级目录下，一章可包含多个场景；编辑器按顺序连续展示本章所有场景。
- 场景名和场景之间的分割线是系统装饰，不属于正文，不会被选中、复制或删除。
- 顶部有场景标题输入框。
- 底部显示字数（汉字数 + 英文单词数）、保存状态、上一/下一场景导航。
- 输入 `/` 唤起斜杠命令；正文右键也打开同一套命令菜单。
- 正文选区被限制在本场景内，跨场景选择、删除、粘贴会被拦或夹回。
- 支持 Ctrl+A 两级全选：第一次选当前块，第二次选本景全部；不会扩到邻景。
- Tab 从当前场景切到下一场景。
- 撤销/重做按场景独立，最多 100 步；结构操作不进入撤销栈。

#### 工具栏

- 撤销 / 重做
- 粗体、斜体、下划线、删除线
- 小标题 H2、三级标题 H3、正文段落、引用、分隔线
- 插入正文插图
- 高亮、清除格式
- AI 摘要、AI 推演、AI 整理提取
- 存片段、＋设定
- 拆分场景 / 删除场景（三级目录）
- 斜杠命令提示

#### 斜杠命令

- 新增节拍
- 推演
- 设定演进
- 分隔线
- 折叠区块·排除 AI
- 折叠区块·注入 AI
- 解除折叠区块
- 插入片段
- 拆分场景 / 删除场景（三级目录）

#### 选区悬浮工具条

选中同一场景内的非空文字后浮出：

- 存片段
- 折叠区块 → 再明确选“不发给 AI”或“仍发给 AI”

点击动作时冻结选区文本、场景 id、内容基线；确认时若原场景被编辑、删除、切书、切景或进入只读，一律拒写并提示重新选字。

#### 右栏信息

- 本景字数
- 视角：从设定集条目中选择
- 标签：显示已分配标签，打开编辑窗
- 摘要/大纲：AI 上下文会使用
- “不发给 AI”开关：整景排除出大纲/前情提要
- 存版本 / 历史版本
- 节拍列表：勾选完成、编辑、AI 成文、删除、添加、AI 生成
- 出场设定：按名称/别名命中列出，显示演进段数，可“＋演进”
- 伏笔快捷标记：埋设 / 呼应 / 回收 / 豁免
- 章交接记忆：查看 / 生成 / 重新生成，带时效徽标

#### 场景版本

- 手动“存版本”保存当前正文 + 摘要快照。
- 每场景保留最近 N 版，默认 10，可设 1–50。
- 历史窗可查看、复制正文、回滚。
- 回滚前会自动为当前内容存一版“回滚前自动存档”，可反悔。
- 当前内容与所有版本都不同时会提示“存在未存档改动”。
- 单版正文/摘要各截断到 50,000 字。

#### 章交接记忆

- 一次调用生成“本章梗概 + 章末交接”。
- 生成期间正文有改动则不保存，避免过期记忆。
- 后续写作的“前情提要”会优先带上最近一章已核定且未过期的交接记忆，再拼接此前场景摘要。
- 正文改动后交接记忆会标记过期，不再用于 AI。

### 3.4 AI 面板（写作页副驾）

#### 两种模式

- **指令**：选一个固定功能发一次请求；结果先存进本书会话，不采用不改作品。
- **对话**：多轮过程，可连续追问；发送不改正文/摘要/节拍/设定，场景改动走提案勾选才写；设定检索只读。

#### 五个固定功能

`生成节拍 / 改写·文风 / 摘要 / 整理提取 / 推演`

- **生成节拍**：生成节拍候选，采用后写入本场景节拍。
- **改写·文风**：对选中文字或整场景生成改写稿，可看差异后替换。
- **摘要**：生成当前写作单元摘要，采用后写入摘要字段。
- **整理提取**：从正文提取设定演进、新设定、伏笔状态迁移候选，逐条确认后写入。
- **推演**：按节拍或写作指引生成正文，可选简略/中等/复杂（约 500/1000/2000 字），预览后插入正文。

#### 确认态

发送前可设置：

- 功能
- 提示词（库内适用项，发送时冻结）
- 推演强度（仅推演）
- 技能（勾选本次装载）
- 关联场景（仅提示词实际引用关联块时出现）
- 上下文：当前场景、前情提要、大纲、设定集注入范围（不注入 / 始终注入项 / 本场景出场 / 全部）
- @ 引用
- 补充要求 / 推演指引

#### 结果与采用

- 每次发送先建会话，请求、提示词、目标书章景、选区、上下文选择在发送时冻结。
- 结果只进会话；可复制、再试一次（原样重放）、新会话、采用。
- 采用是唯一写入作品的入口；同一字段只允许勾一条。
- 采用前核对目标正文指纹；目标已改、已删、只读或冲突时拒写。
- “采用”前会存档；写入成功后刷新采用基线，同一会话可重复采用。
- “再试一次”保留旧结果，不覆盖；换功能请发起新请求。

#### @ 引用

支持五类：

- 内容（正文/摘要/片段）
- 片段
- 提示词
- 设定
- 目录

“内容”选择器支持：

- 按场景勾选正文或摘要
- +1 / +5 / +10 增选正文或摘要
- 关联前文：选当前及之前 N 个场景
- “近期用正文，其余用摘要”
- 撤销上次操作、全部展开/收起
- 已选数量统计

“目录”有三档：

- 全书目录
- 目录 + 设定名录（名称+类型）
- 目录 + 设定名录 + 关联小节（仅标题/id）

目录引用永不灌场景正文，只给索引。

#### 对话/助理模式

助理可使用工具：

- `read`：读数据夹内文件；开启整盘读取后可读数据夹外；机密目录永远读不到
- `find`：按文件名/文件夹名查找，不读正文
- `search`：联网搜索，结果写回同一条对话
- `lookup`：按名称/别名检索设定，只回只读摘要/指针
- `open`：打开/定位场景，仅导航
- `skill-load`：按需装载技能正文或参考文件
- `edit` / `write`：对正文、摘要、节拍、已有设定字段留下提案
- `mcp`：调用外部 MCP 工具

助理不能执行命令；所有改稿都走提案卡，勾选确认才写入。提案目标在发送时锁定，目标已变、已删、只读或冲突时不写。

助理还会识别“新建章节/新建场景”的常见说法，弹出轻确认条：可改标题、创建并发送、不创建只发送、取消。不会静默直建。

#### 拖卡访谈

- 设定卡可拖出，在落点打开浮窗。
- 角色卡 → 角色扮演访谈；非角色卡 → 设定助理对话。
- 每次强制新开；有内容发送后才建档；空聊不建档。
- 访谈记录进入资源栏“对话”的“访谈”分组。

### 3.5 审阅

#### 项目统计

- 总字数
- 场景数
- 章节数
- 设定条目数
- 伏笔数
- 目标字数进度条
- 导出成稿入口

#### 检查清单

按以下规则列出问题，条目可点击跳转：

- 场景缺少摘要（影响 AI 前情提要质量）
- 场景未设置视角
- 章节没有场景
- 设定条目从未在正文出现（名称/别名零命中）
- 关联指向不存在的条目
- 伏笔已过预期回收点仍未回收
- 伏笔临近预期回收点（差 ≤3 场）

#### AI 审稿（逐项目标）

1. 选择章节。
2. 目标清单从节拍、章摘要、未截断场景摘要中冻结生成。
3. 一次调用逐项核对，每项给出已落实/未落实/待核实。
4. 判断必须带正文逐字引文；无有效引文标“待核实”并标警示。
5. 模型自创目标 id 或结构异常时，全部标待核实，建议重跑。
6. 作者逐条处置：纳入修稿、编辑意见、忽略/恢复、新增人工问题。
7. 只对勾选的问题生成修订候选，一次处理所选问题。
8. 候选以折叠区块差异对比呈现，未变行默认折叠。
9. 点“采纳”才写入目标场景；单场景修订。
10. 采纳记录可查看差异、恢复此版；正文已变化时候选过期拒写。

#### 伏笔

五个状态：

`计划 → 已埋 → 已呼应 → 已回收`

以及“已放弃”（只能从计划/已埋转入）。终态不可再流转，只能删除重建。

字段：标题、备注、状态、埋设场景、呼应场景（多选）、回收场景、预期回收场景、豁免提醒。

- 逾期/临近以“写作进度序”为基准；临近＝预期回收还差 ≤3 场。
- 已回收/已放弃不提醒；豁免后不再提醒，但仍会注入 AI。
- 写作页右栏可对当前场景快捷标记埋设/呼应/回收。
- 审阅页伏笔面板可新建、编辑、豁免。

#### 设定出场热力图

- 行＝设定条目（按提及次数取前 25）
- 列＝场景序号（最多前 80 个场景）
- 颜色越深，出场次数越多

#### 设定矛盾检查

- 本地规则先扫，另可接“审阅专用模型”做决策层。
- 检查设定描述/演进与场景正文是否矛盾。
- 冲突概率达到门槛才进清单；低于门槛但 ≥0.4 为灰区“不确定”。
- 默认门槛 0.7，可设 0.4–0.95；可显示分数与门槛数字。
- 内容变化后出现“是否审阅检查”横幅；可运行、稍后。
- 开启“静默审阅”后，闲置达到等待时间且内容有变才自动跑决策层，默认 300 秒，可设 30–3600 秒。
- 冲突条目可展开看设定侧/正文侧原文切片，跳前文/后文/设定。
- 可忽略；设定或正文改动后忽略自动解除。
- 审阅模型未配置时仍可用本地规则。

### 3.6 设定集（资源栏）

#### 条目类型

六个固定类型，不再按每本书自建分类分组：

`角色 / 地点 / 物品 / 世界设定 / 支线 / 其他`

#### 列表

- 搜索：名称 / 描述 / 类型 / 标签
- 筛选漏斗：有关联、有注释、有描述、有附图、有标签、全局、有别名、有设定演进、在当前场景；支持“有/无”三态循环
- 排序：按提及次数 / 按名称
- 按六类型分组，组头显示计数，可折叠；查询期显示“匹配数/总数”
- 每组组头有“＋”，新建时预选该类型
- 批量管理：勾选多条后可改色、恢复分类色、追加标签、清空标签、批量删除

#### 条目编辑

实时保存：改动去抖约 400ms 落盘，无“保存/取消”按钮；首次改动才创建条目。

五个页签：

1. **详情**：类型、名称、标签、别名、描述、设定演进、导入记录
2. **笔记**：笔记内容不会被 AI 引用
3. **关系**：归属 / 下属 / 关联
4. **提及**：正文名称/别名命中，可打开写作定位
5. **追踪**：四种纳入方式

#### 关系

三种关系：

- 归属条目
- 下属条目
- 关联条目

一条设定可以有多个关系；关联可写注释；归属方向可一键反转；不能和自己建立关系；已存在其他关系时再加一种会先询问，可“不再提示”；批量/搜索选择对端时可按类型筛选。

#### 提及

- 正文中名称/别名至少 2 字才参与扫描。
- 按场景统计命中次数，可打开写作定位。
- “从不包含”不追踪提及。
- 可关闭“追踪别名”；关闭后别名不计入提及次数。

#### 追踪四态

- **始终注入**：每次 AI 调用都带上。
- **检测到时包含**：正文/指令/对话命中时自动加入上下文。
- **检测到时不包含**：仅通过对话 @ 引用手动加入。
- **从不包含**：@ 列表不出现，不自动注入，不统计提及。

新建条目默认值可在设置→系统里设；已有“检测到时包含/不包含”可批量统一（始终注入/从不包含不动）。

带“AI 上下文”标记的字段才会被引用：梗概、摘要、别名、描述、设定演进等；笔记不会。

#### 设定演进

- 每条演进可指定“从哪个场景起生效”。
- AI 按当前写作位置自动采用生效中的阶段设定。
- 写作页右栏出场设定可“＋演进”快速添加。
- 从设定包导入的原场景演进会转成“导入记录”，只作回溯，不在本书生效，也不注入 AI。

#### 提取设定

入口：

- 设定集面板“提取角色”
- 书籍卡“提取”
- 参考资料条目行“提取”

支持五种类型：角色、地点、物品、世界设定、支线；默认勾选前四类，支线默认不勾。

流程：

1. 展示取用范围、规模、用途、发送端点、模型、分段方式。
2. 选择提取类型、书籍章节范围或材料全文、提取方式。
3. 确认后才外发。
4. 结果先出候选，预览确认后合并到设定集。
5. 本书尚无已保存设定时，提取结果可直接落盘；已有设定时走候选确认。
6. 引文/代表段落作证据；无有效引文的候选丢弃。
7. 同名/同别名合并；作者已有字段优先。

#### AI 服务详解

- 多条连接，每条各自保存 Base / Key / 模型 / 思考强度 / 附加 JSON；切换连接即切换当前接口、密钥与模型。

- 思考强度：默认不发送；多数 OpenAI 兼容端发 `reasoning_effort`；OpenRouter 改为 `reasoning.effort`；其它厂商字段用附加 JSON。

**开发者模式**

- 默认关；开启后顶栏右端出现 DEV 徽标。

- 累计按模块拆分。
- 端点返回 usage 时优先使用；缺失时估算并标注“估算”。

#### 数据管理详解

- 数据文件夹路径可留空用默认；切换只改认领路径，不搬家；保存后整页重载。

- 静默审阅：等待 30–3600 秒；开关；显示冲突分数/门槛；门槛 0.4–0.95，默认 0.7。
- 场景版本容量 1–50，默认 10；显示版本占用估算。

- “导出全部数据”是整库 JSON 备份，设置会剔密；但“导入数据”主要合并书稿实体，不恢复设置与密钥。完整迁移更可靠的方式是拷贝整个数据文件夹，然后重新填写 API Key。
- “清空全部数据”是危险操作，需二次确认。

## 四、AI 上下文与安全边界

### 4.1 上下文分层

AI 请求按层装配，超上下文窗口时按 L3 → L2 → L1 整层丢弃：

- **L0 永不裁**：提示词模板、任务指令、对话历史、小体量元数据（梗概/摘要/节拍）。
- **L1**：当前场景全文、前情提要、光标前文、关联场景。
- **L2**：设定注入、大纲、未回收伏笔清单。
- **L3**：提示词引用的样章片段。

前情提要＝最近一章已核定且未过期的交接记忆 + 此前场景摘要。当前场景被排除出 AI（`noAi`）时，其内容不会经交接记忆泄漏。

### 4.2 上下文选择

写作页 AI 面板提供：

- 当前场景
- 前情提要
- 大纲
- 设定集注入范围：不注入 / 始终注入项 / 本场景出场 / 全部
- 关联场景（自动最近 1/3/5/10 场或全部；手动逐景选正文/摘要）
- 技能
- 提示词
- @ 引用

AI 面板会显示上下文摘要和预算行，说明这次到底带了什么、哪层被裁。

### 4.3 写入安全

- 固定功能结果只进会话，不直接改作品；必须“采用”。
- 采用前校验目标正文指纹；目标已改、已删、只读、冲突时拒写。
- 整理提取走独立候选管线：候选必须带正文逐字引文，无引文丢弃；确认前零写入。
- AI 审稿的修订候选必须“采纳”才写入目标场景；采纳有台账，可恢复。
- 助理改稿一律走提案卡；勾选确认才写入；目标发送时锁定。
- 续写/推演有“重复门禁”：结果开头与上文 ≥80 字连续重演时高亮并二次确认。
- 章交接记忆、场景版本、修订候选都有“生成期间正文已变则拒写”的守卫。

### 4.4 隐私与权限

- API Key 只存本机，用当前 Windows 账号加密，导出包不含。
- 助理读取文件默认限数据夹；整盘读取默认关；机密目录永远读不到。
- 助理不能执行命令。
- 联网搜索经本地服务中转，不看整盘读取开关。
- MCP 连接本机工具；外部副作用可设每次确认。
- 开发者发送记录只在内存，关程序即消失。

## 五、导入、导出与备份

### 5.1 导入

| 入口 | 支持内容 | 关键边界 |
|---|---|---|
| 我的小说 → 导入文档 | Word `.docx` / TXT / MD | 先预览核对；导入为新书或参考资料；取消零写入 |
| 设置 → 数据管理 → 导入数据 | 本应用 JSON、novelcrafter | 主要合并书稿实体；不恢复设置与密钥 |
| 设置 → 提示词 → 导入提示词 JSON | 整包/单条 | 内置保护；整包冲突逐条保留/覆盖 |
| 设置 → 提示词 → 导入大纲模板 | JSON | 建书或既有作品应用模板 |
| 设置 → 数据管理 / 书籍卡 → 导入设定包 | 设定包 JSON | 导入为独立条目，不覆盖现有；包外关联剥离；原场景演进转历史 |
| 我的小说 → 提取 / 设定集 → 提取角色 | 书正文或参考资料 | 先披露、确认才外发；候选确认才写入 |

### 5.2 导出

| 入口 | 内容 |
|---|---|
| 我的小说 / 审阅 → 导出成稿 | 选场景、仅正文/仅摘要/正文+摘要、卷/章/场景标题、场景分隔符、Markdown 或 Word |
| 设置 → 数据管理 / 书籍卡 → 导出本书 JSON | 本书实体；可选附带“设定快照”（记录每条设定与内容 hash，供日后核对） |
| 书籍卡 → 导出设定包 | 全部条目或按六类型筛选；只带选中条目与实际用到的分类；不含密钥与跨书链接 |
| 设置 → 数据管理 → 导出全部数据 | 整库 JSON 备份，设置剔密，不含 API Key |
| 设置 → 提示词 → 整包导出 | 全部非内置提示词 JSON |

### 5.3 迁移与备份要点

- 最可靠迁移：拷贝整个数据文件夹，然后在新机器/新 Windows 账号重新填写 API Key。
- “导出全部数据”不是完整设置恢复包；“导入数据”主要恢复书稿。
- 提示词、设定包、大纲模板有各自的导入/导出。
- 删整本书不可恢复；卷/章/场景删除进作品回收站。
- 正文里按 Delete/Backspace 删字不会进回收站。
- 数据夹文件级删除（技能、片段等）会进数据夹回收站。
