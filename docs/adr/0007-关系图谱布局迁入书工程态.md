# 关系图谱布局迁入书工程态

关系图谱节点坐标原只记 UI 布局 `S.ui.graphLayout[novelId][entryId]={x,y}`（localStorage `UI_KEY`，旧口径「不进作品文件」），换设备或清缓存即丢整书精心摆放；同期剧情图谱坐标／边／钉住已落书根 `剧情图谱.json`，同属图谱摆位的数据两套口径并存。决定：布局坐标迁入书根 `关系图谱.json`（`{entryId:{x,y}}`），首次打开某书且书内无该文件而 `UI_KEY` 有该书布局时自动迁入并清除旧值，之后 localStorage 不再写布局；缩放比例与工具栏开关仍属视图偏好，留在 `UI_KEY`。本 ADR 推翻 CONTEXT.md「关系图谱占位与让位」中「不进作品文件」旧口径。

## Considered Options

- 维持 localStorage（现状）：换机即丢，与剧情图谱口径不一；拒绝。
- 并入 `剧情图谱.json`：两图谱数据语义混装、文件名误导；拒绝。
- 书根独立 `关系图谱.json`（采纳）：与剧情图谱并列、一书一文件、只含坐标；设定包不含布局，不受影响。

## Consequences

- 书文件夹多一个 json 文件；写盘需节流（沿拖动松手落盘节奏），撤销栈仍为会话态不落盘。
- 迁移一次性且单向：迁入成功即清 localStorage 旧布局防双源漂移；迁移失败保留旧值、不破坏现状。
- 缩放（graphScale）不随迁：属视图偏好，换机重置可接受。
