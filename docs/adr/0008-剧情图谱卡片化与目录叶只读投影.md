# 剧情图谱卡片化与目录叶只读投影

剧情图谱 MVP 节点为圆形（章 r=18／小节 r=15），只承载标题；剧情内容天然需要一段文字作引子，圆形对大体量文本阅读几乎无用，图谱完成度受限。同期关系图谱完成 draw.io 手势增强（悬停拉线、布局撤销、适配等），剧情图谱全缺。决定：剧情图谱节点改为统一固定尺寸的方形卡片（约 220×96 世界单位），卡片引子＝目录叶既有文本的只读投影——优先级：小节摘要 → 小节节拍首条 → 章梗概（章交接记忆）→ 空；不新建「剧情词条」实体、引子不落 `剧情图谱.json`，改文字仍走写作页。卡片化版本首开触发一次性整卷重铺（按目录顺序网格＋卡片间距重算全部坐标，边与钉住保留、旧坐标弃）。缩放范围两图统一 10%–400%（推翻旧「剧情图谱 25%–300%」口径）。

## Considered Options

- 新「剧情词条」实体（每节点自带引子正文、图谱内可编辑）：与目录摘要双源打架、`剧情图谱.json` 膨胀、突破「图谱内不改正文」既有裁定；拒绝。
- 保留圆形＋仅悬停提示文字：不解决并排比对多段剧情引子的核心读法；拒绝。
- 目录叶只读投影＋方形卡片（采纳）：真源唯一（状态边车／章 json），卡片只是展示层，改动集中于渲染与铺点。

## Consequences

- 边端点从圆周改为连线与卡片边框最近交点；`data-r` 半径语义改半宽高，拖动同步、命中、箭头锚点、铺点间距随之调整。
- 首开重铺单向一次性（同 ADR 0007 迁移哲学）：MVP 期短、坐标多为自动网格产物，旧坐标不备份；格式版本升级承载该迁移，换设备后再开不重复重铺。
- 无摘要／无节拍／无梗概的叶显示同高空卡（标题仍在），倒逼回写作页补概览，不倒逼图谱造数据。
- 两图缩放统一后，原 CONTEXT「剧情图谱仍为 25%–300%」口径作废，「关系图谱画布」术语同步修订为两图共用画布。
