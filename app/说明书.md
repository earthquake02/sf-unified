# 故事工坊 · 应用手册

> 本手册是应用唯一说明文件：安装启动、数据契约、AI 行为与功能要点、常见问题。只描述当前版本。

## 一、安装与启动

- **双击 `故事工坊.exe`**：同一进程内绑本机 `127.0.0.1` 起本地服务并开壳窗口（Tauri＋WebView2）。一个窗口＝程序本体，**关掉窗口＝停服务**；程序已在运行时把已有窗口前置、不另开窗口。
- **首次启动**：窗口里是服务控制台页 → 「① 数据文件夹」填一个路径（不存在会自动创建；留空直接保存＝在 exe 旁自动创建「故事工坊数据」）→ 同一窗口进入写作界面。
- **排查口**：命令行 `故事工坊.exe --no-window`＝只起服务不开窗口，浏览器手工访问控制台页地址。
- **不要直接双击 `index.html`**（file:// 拿不到数据文件夹，只显示引导页）；程序页由服务承载。
- **源码运行（开发/排查）**：`cargo build --manifest-path app/server-rs/Cargo.toml` 后跑 `app/server-rs/target/<debug|release>/sf-server.exe`。
- **构建发布**：`node tools/release_rust.mjs` → `release/rust/故事工坊.exe`（Windows 单 exe；升级＝替换 exe，数据文件夹不动）。
- 快速核验（不构建）：`node tools/dev_page.mjs`——现有 exe 经 `--app` 服务仓内 `app/index.html`＋隔离数据夹。

## 二、数据文件夹与端点契约

### 布局（结构化文本：一景一文件、零转换、无 manifest）

```
数据文件夹/
├── _工坊/                              ← 全局资产（跨书）
│   ├── 提示词.json                      ← 用户提示词（内置提示词是代码资产不入文件）
│   ├── 文风.json                        ← 已退役（旧画像；真源改 _工坊/技能/style-*/SKILL.md）
│   ├── 用量.json / 大纲预设.json
│   ├── settings.json                    ← 设置（不含 Key）
│   ├── 字体/<名字>.font.txt              ← 放入的字体（文本承载字节）
│   ├── 机密/AI密钥.dat                   ← Key 密文（DPAPI，仅 /api/secret/* 读写）
│   ├── 技能/                            ← 技能资产（SKILL.md 等）
│   ├── 回收站/<时间戳>/<原相对路径>      ← 一切删除的落点（可回溯）
│   └── 服务锁.json                      ← 服务实例锁
└── 《书名》/                            ← 一部书
    ├── 项目.json                        ← 身份锚（书名/id/schemaVersion/封面等）
    ├── 标签.json                        ← 作品级受控标签定义
    ├── 正文/<卷名>/卷.json
    ├── 正文/<卷名>/<章名>/章.json        ← 章元数据（含交接记忆/修稿闭环）
    ├── 正文/<卷名>/<章名>/<场景名>.html  ← 场景正文（contenteditable HTML 原样进出）
    ├── 正文/<卷名>/<章名>/<场景名>.json  ← 同景状态边车（摘要/标签分配/节拍/版本快照）
    ├── 设定/<分类>/_分类.json ＋ <条目名>.md   ← 一条设定一文件（md＋YAML front matter）
    ├── 伏笔/<标题>.md ／ 片段/<标题>.md
    ├── 会话/<标题>.json                  ← 旧多消息 AI 会话（只读保留）
    ├── 对话/<标题>.json                  ← 固定功能会话（副驾等）
    ├── 图/<身份>.png.txt                 ← 图像素（配图/正文插图按身份引用）
    └── 素材/ ／ 快照/                    ← 程序不读不写（整书删除时随目录入回收站）
```

### 读写口径

- **正文落 HTML 不落 Markdown**：零转换层，浏览器双击即得成稿视图；设定/伏笔/片段落 md＋front matter。
- **路径名一经落盘即稳定**：改标题不搬文件，文件内标题才是真源；手工改名文件可被认领，手工挪位元数据会丢。
- **写盘**：内存投影与文件账本逐文件比对，只写变化文件；一律带 `baseHash` CAS——他方先改即拒写、弹「数据文件已被其他窗口或程序改动」，出路＝重新载入或以本窗口为准覆盖（他方版本先进回收站）。自动保存默认停止编辑约 1 秒写入，最长间隔 300 秒（设置页可改 30~3600）。
- **删除一律进数据夹内回收站**（`_工坊/回收站/`），可回溯。
- **不认识的文件零触碰**：非契约形态只读不认领、不删；解析不了的进「跳过项」告警。
- **机密**：AI Key 只存 `_工坊/机密/AI密钥.dat`（DPAPI 绑 Windows 账号）；`settings.json` 与一切导出包不含 Key 明文。换机/换账号后密文解不开＝重填一次 Key。
- **版本闸门**：每书 `项目.json` 记 `schemaVersion`；数据版本高于程序支持时整场只读（不写回、不迁移）。

### 本地服务端点（`app/server-rs/src/http.rs`）

| 端点 | 方法 | 用途 |
|---|---|---|
| `/api/sys/status` | GET | 服务状态/版本 |
| `/api/sys/config` | POST | 数据文件夹配置（控制台页） |
| `/api/sys/open-data` | POST | 打开数据文件夹 |
| `/api/fs/read` | GET | 读文件 |
| `/api/fs/write` | POST | 写文件（带 baseHash CAS） |
| `/api/fs/mkdir` / `/api/fs/delete` | POST | 建目录／删除（回收站） |
| `/api/fs/list` / `/api/fs/stat` | GET | 枚举／元数据 |
| `/api/fs/snapshot` | GET | 一次性契约目录快照（启动扫描首选） |
| `/api/disk/read` | GET | 助理整盘读取（受限） |
| `/api/secret/read` / `/api/secret/write` | GET/POST | 机密密文读写（仅此两端点可碰机密目录） |
| `/api/ai/models` / `/api/ai/chat` | POST | AI 代理（拉模型列表／流式对话） |
| `/api/search` | POST | 数据夹内搜索 |
| `/api/mcp/status|connect|disconnect|list|call` | POST | MCP 通道管理 |

服务只绑 `127.0.0.1`，带令牌与 Origin 安全闸；`/api/ai/chat` 为流式转发（BYOK 直连你配置的端点）。

## 三、AI 行为（BYOK、提示词全库）

### BYOK 配置

支持任何 OpenAI 兼容端点，程序不预置任何厂商地址。设置 → AI 服务 → 填 Base 与 Key → 测试连接 → 拉取模型列表（端点 `/models` 报什么列什么、不过滤，哪个能用由你认）。「＋新增」可加多组配置，切换选中即切换生效。**Key 只留在本机**（DPAPI 密文）；「导入数据」不恢复 AI 配置，换机＝导入书稿＋重填一次 Key。

### 上下文注入（四层）

| 层 | 内容 | 超窗时 |
|---|---|---|
| L0 | 指令元数据 | 不裁 |
| L1 | 当前场景正文、前情提要、前章交接记忆 | 整层裁剪有痕 |
| L2 | 设定集（按位置套设定演进）、大纲 | 同上 |
| L3 | 全书正文、风格样章 | 同上 |

上下文窗口默认「自动」按模型名猜（猜不到按 8K 保守）；本地大窗口模型请手填实际窗口。生成弹窗底部「预算行」显示本次注入哪层、估算 token、窗口来源。

### 提示词资产

- **内置提示词 19 条**（代码内 `builtinPrompts()`，只读随版本刷新，要改先「克隆」）：角色访谈、场景摘要、改写/扩写/缩写、节拍生成、节拍推演（核心写作提示词，含裁决链/冲突报告/衔接纪律）、章后整理、章交接记忆、逐项目标审稿、按审稿意见修订、文风蒸馏、互动校准、JSON 结构修复（管线内部无界面入口）、组件/默认上下文、组件/设定集。
- **SF 提示词包**：`storyforge-提示词导入.json`（16 条方法提示词）与 `storyforge-提示词全库.json`（137 条全量），从提示词库页导入；小说类入「工作坊对话」，漫剧/剧本类入「自定义」。
- **模板语法**（兼容 novelcrafter aic2 子集）：`{novel.title}`、`{scene.text}`、`{scene.summary}`、`{outline}`、`{storySoFar}`、`{codex.all}`、`{fullText}`、`{message}`、`{wordTarget}`、`{textBefore}`（光标前最近正文）、`{snippet.get("标题")}`、`{#if x}…{#endif}`（可嵌套）、`{include("组件/…")}`、`{wordCount(message)}`、`{either(input("…"), "fallback")}`。变量白名单见应用内「语法帮助」；`{input("…")}` 无数据源不要用。JSON 输出示例的花括号必须带引号键。

### AI 入口一览

| 入口 | 干什么 |
|---|---|
| 节拍「✦写」／工具栏「✦ 推演」 | 按节拍/自由续写生成正文（同一提示词） |
| 工具栏「✦ 执行」 | 选中文字改写/扩写/缩写（修订安全协议：修订稿＋修改对照表） |
| 「✦ 整理提取」 | 章后整理：设定演进/新设定/伏笔状态迁移候选，逐字引文校验，勾选才写入 |
| 右栏「生成交接记忆」 | 章→章梗概＋章末交接；正文改过标「已过期」停注 |
| 副驾「💬」 | 固定功能请求（如节拍生成）：发送才建会话，结果经「✓ 采用」确认才写入目标 |
| 审阅「🎯 AI 审稿」 | 冻结目标清单逐项 completed/unmet/unknown＋逐字引文；模型自创目标 id／结构异常时整段降为「待核实」并提示重跑 |
| 审阅「✦ 生成修订候选」 | 审稿-修稿闭环：确认项→修订候选→差异对比→手工采纳 |
| 书卡「🧩 提取」 | 从正文/导入材料提取设定候选（角色/地点/物品/世界设定/支线） |
| 「🎨 文风蒸馏」 | 文风画像与互动校准（实验性，效果不承诺） |
| 设定集「✦ 整理提取」 | 同章后整理的候选写入途径 |

所有 AI 结果走候选确认或守卫写回（CAS＋过期守卫）；AI 只把你勾选的上下文发给你自己配置的服务商。

## 四、功能要点

**导航**＝顶部五页（我的小说／故事板／写作／审阅／设置）＋左侧资源栏（设定集／片段库／对话）。

**核心写作循环**：规划（故事板/大纲搭卷章场景、写摘要）→ 设定（设定集建条目、中后期用设定演进）→ 写作（节拍「✦写」生成正文、手工修订）→ 润色（选中文字「✦ 执行」）→ 检视（审阅体检/热力图）→ 交稿（导出 Markdown/Word，勾选场景）。

## 五、常见问题

- **拉取模型列表不过滤**：端点报几个列几个（含嵌入/绘图等非对话模型），自己认哪个能用。
- **maxTokens 过低会截断**：截断与「疑似未完成」会出黄色横幅；长文生成建议 maxTokens ≥ 4096；思考型模型的思考也吃 maxTokens。
- **目标字数是下限参考**：提示词不为凑字数删改原文；整场景扩写默认 400 偏小，按需手调。
- **提及两套口径**：热力图/矩阵「◆正文提及」/条目「提及」Tab 按 AI 可见正文计（不含排除AI折叠块）；右栏「出场设定」可能仍算进去（已知边界）。提及索引按书、有效名称/别名和场景正文缓存：首次每景单遍匹配，无关保存不重扫，修改正文只重扫该景，改标题只更新展示；匹配规则改变才重建本书索引。
- **纯净阅读类提示词**（如 SF·首章盲读）：建议新开会话并关掉上下文注入勾选。
- **本地大窗口模型**（如 256K）：到设置手填实际窗口，否则误判超窗、上下文被整层裁剪。
- **写入时机**：停止编辑约 1 秒写入；连续编辑最多 300 秒（可调）必写一次；强杀浏览器可能丢最后一次改动——页脚指示「待写入/已保存」。
- **升级后的章交接记忆哈希迁移**：场景纯文本口径已统一为块级换行（ADR 0004）。旧版持久化的章交接记忆会按存档哈希前缀（`sha256:` / `fnv1a64:`）用旧口径校验后自动迁移；校验不过的保持原状——过期仍过期、缺基线仍需重新生成，不会因迁移复活。
- **多标签互踩**：同一数据夹开两个标签，后写者被服务端拒写并弹冲突横幅；出路＝重新载入／以本窗口为准覆盖（他方版本进回收站）。
- **写入失败**：数据夹被删/占用/服务停时顶部横幅「最近一次写入失败」＋重试；数据仍在内存。
- **file:// 直开 index.html 只显示引导页**：有意为之，用 exe 打开。
- **换机/换 Windows 账号后 Key 失效**：DPAPI 绑账号，重填一次即可。
- **路径名不随标题刷新**：文件内标题是真源；手工改名文件可认领、手工挪位会丢章元数据。
- **删除都可回溯**：一切删除进数据夹内回收站（删整本书＝整棵目录一次入回收站）。
- **旧库（`_工坊/书库.json`）自动迁移**：打开时一次性迁为结构化文本，成功后旧库入回收站；中途失败可断点续迁。
- **场景版本单版 5 万字截断、采纳记录 8 条/章 12 万字符封顶**：超限挤最旧，重要版本自行另存。
- **重复导入同一 JSON 会生成重复的书**：每文件只导一次。
- **导入章节切分**：支持「第N章／Chapter N／序章类」与裸中文数字编号（如「一豪雨白衣」「二一一命一诺」）。裸编号的数字前缀按全书序列上下文解析（题名自身以数字开头时不会贪心吃掉），跳号/原站错号会重同步并在导入前核对弹窗提示；偶发误切/漏切以核对结果为准。
- **「内置只读」是界面护栏不是安全边界**：控制台手段可绕过。
