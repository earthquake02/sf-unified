# 表达层信号（按需查阅）

出现≠必错；跨场景机械复现、成片堆叠、或只贴标签不写内容时优先处理。

## 高优先级信号

| 信号 | 例子／形态 | 问什么 |
|---|---|---|
| 否定翻转铺排 | 不是 A，而是 B；不是…也不是…只是… | 是否先打无人在意的靶子再宣布结论？ |
| 万能状语／声线 | 带着一丝…；声音不大却带着…；平静无波 | 是否只有抽象态度，没有可辨内容？ |
| 解释结论链 | 这意味着；终于明白；由此可见 | 是否把读者已懂的再总结一遍？ |
| 空泛收束／预告 | 命运齿轮；故事才刚刚开始；殊不知 | 是否空宣告或越披露边界？ |
| 告知贴标签 | 他知道…；她感到…；显得有些 X | 能否改成可见行动或具体念头？ |
| 电报体动作清单 | 连续孤立短句；抬手、取过、放下 | 方向、对象、连接是否丢了？ |
| 套词反应 | 深吸一口气、眼中闪过、嘴角勾起、指节泛白 | 是否每场同一套？ |
| 万能景物 | 阳光透过窗帘…空气中弥漫着淡淡的… | 能否挪到任意场景？能则删或绑到当下行动 |

## 误改风险（不要为了去词而伤信息）

- 「美丽」「白色」「因为害怕」等修饰／原因可能在区分或承接——不能一律剁成残句。
- 「仿佛／好像／似乎」可表视角不确定；「坚定／冰冷」可是准确描述。
- 不要把温和请求改成辱骂，或凭空补锁门、录音、围观人群。
- 二修伪自然：连续「伸手／取过／放下」或强加口误脏话，也是另一种套式。
